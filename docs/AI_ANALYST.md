# AI Analyst

## Overview

The AI Analyst layer is responsible for analyzing structured security
findings produced by the deterministic detection engine.

The AI Analyst does not process raw security logs directly.

The current pipeline is:

Security Log
→ Parser
→ Detection Engine
→ SecurityFinding
→ AI Input
→ Gemini
→ AIAnalysis
→ Security Report

The detection engine identifies suspicious activity using deterministic
rules. The AI Analyst then explains the finding, maps it to MITRE ATT&CK,
assesses confidence, and recommends defensive actions.

---

## 1. AI Input

The AI Analyst receives a structured security finding generated by the
detection engine.

The input currently contains:

- `ip_address` — Source IP associated with the activity.
- `attack_type` — Attack classification generated by the detector.
- `severity` — Severity assigned by the detection engine.
- `failed_attempts` — Number of failed authentication attempts.
- `targeted_users` — User accounts targeted by the activity.
- `time_span` — Detection window in minutes.
- `first_seen` — Timestamp of the first observed activity.
- `last_seen` — Timestamp of the last observed activity.
- `evidence` — Evidence collected by the detection engine.

The conversion from `SecurityFinding` to AI input is handled by
`src/ai_analyst.py`.

---

## 2. What the AI Analyst Does

The AI Analyst receives the structured finding and produces a security
analysis.

It is responsible for:

1. Summarizing the incident.
2. Explaining why the activity is suspicious.
3. Identifying a relevant MITRE ATT&CK technique.
4. Presenting supporting evidence.
5. Assigning a confidence level.
6. Recommending defensive actions.

The AI is instructed not to invent evidence or claim that an attack
succeeded unless the supplied finding contains evidence of a successful
compromise.

---

## 3. LLM Provider

The current implementation uses Google's Gemini API.

The Gemini client is implemented in:

`src/ai_client.py`

The application sends the structured security finding to Gemini along
with instructions describing the required analysis.

Gemini is configured to return JSON matching the project's `AIAnalysis`
Pydantic schema.

---

## 4. AIAnalysis Output

The AI Analyst returns an `AIAnalysis` object defined in:

`src/ai_schema.py`

The output contains:

### Incident Summary

A concise explanation of what happened.

### Why Suspicious

A list of reasons explaining why the detected activity is suspicious.

### MITRE ATT&CK

The relevant MITRE ATT&CK tactic and technique.

The current schema contains:

- `tactic`
- `technique_id`
- `technique`

### Evidence

A list of facts from the security finding supporting the analysis.

### Confidence

The AI's confidence in its assessment.

### Recommended Actions

Practical defensive actions that a security analyst can take.
